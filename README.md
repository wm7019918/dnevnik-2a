# Дневник 2А

Школьный дневник для iPhone: уроки с понедельника по пятницу, домашние задания, оценки,
тренировки по БЖЖ (вт и чт в 19:00, сб в 10:30) и напоминания попить воды.

## Как установить на iPhone

1. Откройте ссылку на дневник **в Safari**.
2. Нажмите «Поделиться» (квадрат со стрелкой вверх) → **«На экран „Домой“»** → «Добавить».
3. Запускайте дневник с иконки «2А», как обычное приложение. После первого запуска он работает и без интернета.

## Напоминания

- Внутри дневника: о воде каждый час и о тренировке за час до начала. Они срабатывают, пока дневник открыт.
- Чтобы напоминания приходили всегда, в дневнике есть блок «Напоминания в Календаре».
  Нажмите кнопку, затем «Добавить все»: события появятся в Календаре iPhone со звуковыми уведомлениями.

## Где хранятся записи

Только на этом телефоне, в памяти приложения. Сервера нет, на GitHub лежит лишь код.
